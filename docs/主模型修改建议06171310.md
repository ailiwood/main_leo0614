# 主模型修改建议06171310.md

> 阶段建议：P5A  
> 建议模型名：Text-Guided AWAF-xLSTM  
> 目标：在不抛弃 xLSTM/sLSTM 与 AWAF 核心创新的前提下，解决 MOSI 当前“Text 主导、Audio/Vision 增益有限”的瓶颈，并兼容后续 MOSEI SDK 特征。

---

## 1. 当前事实判断

P4Z 已经排除 MOSI 数据错位作为主要原因：2199 IDs、split 正常、无 NaN、无明显泄漏。当前瓶颈主要来自模型与特征利用方式：Text-only 约 76.2%，Full AWAF-Seq 约 78.8%，多模态净增益只有约 +2.6%。这说明模型不是不能融合，而是 Audio/Vision 没有形成足够强的、稳定的修正贡献。

P4W 的 4 组调参也说明，简单增大 hidden_dim、cross_layers 或 batch_size 均未提升。因此下一步不应盲目堆大模型，而应改变融合机制：从“三模态平等竞争”转为“文本锚点 + 弱模态可靠性修正 + AWAF 样本级解释融合”。

---

## 2. 新主模型候选：Text-Guided AWAF-xLSTM

### 2.1 总体结构

```text
text/audio/vision 序列输入
  ↓
三模态独立 projection
  ↓
三路 sLSTM 时序编码
  ↓
序列级 Cross-modal Transformer
  ↓
Masked Attention Pooling 得到 h_t, h_a, h_v
  ↓
Modality Reliability Gate 得到 r_t, r_a, r_v
  ↓
Text-Anchor Residual Correction:
    h_anchor = LN(h_t + r_a * A(h_a) + r_v * V(h_v))
  ↓
AWAF(h_t', h_a', h_v') 输出 z_awaf 和 w_t,w_a,w_v
  ↓
Final Fusion:
    z = LN(z_awaf + λ * h_anchor)
  ↓
regression head + classification head + unimodal auxiliary heads
```

### 2.2 为什么这样设计

Text-only 已经较强，说明文本是稳定主干；Audio/Vision 如果直接平等融合，容易成为弱噪声或弱增益。新结构让文本作为 anchor，让 Audio/Vision 通过 reliability gate 进行样本级修正。AWAF 仍然保留，负责输出三模态样本级权重和论文解释性。

---

## 3. 关键模块

### 3.1 ModalityReliabilityGate

输入：

```text
h_t, h_a, h_v ∈ R^d
```

拼接：

```text
[h_t, h_a, h_v, |h_t-h_a|, |h_t-h_v|, h_t⊙h_a, h_t⊙h_v]
```

输出：

```text
r = [r_t, r_a, r_v] ∈ [0,1]^3
```

其中 `r_a` / `r_v` 控制音频/视觉对文本 anchor 的修正强度。

### 3.2 Text-Anchor Residual Correction

```text
h_anchor = LN(h_t + r_a * W_a h_a + r_v * W_v h_v)
```

该结构不是文本单模态模型，而是文本为主、弱模态动态修正。

### 3.3 Final Fusion

```text
z_awaf = AWAF(h_t', h_a', h_v')
z = LN(z_awaf + λ * h_anchor)
```

`λ` 是可学习标量，初始化建议 0.5。

---

## 4. 为什么兼容 MOSEI

MOSEI SDK 特征维度通常为：GloVe 300、COVAREP 74、FACET 35。低维弱模态更容易在平等融合里拖累模型。Text-Guided 结构更适合 MOSEI：GloVe 文本作为 anchor，COVAREP/FACET 作为可靠性修正，AWAF 仍输出样本级权重。输入维度完全由 config 控制，可同时适配 MOSI 强特征和 MOSEI SDK 低维特征。

---

## 5. 实验进入条件

新模型必须先通过：

1. MOSI random forward/backward；
2. MOSEI-dim random forward/backward；
3. MOSI 3ep smoke；
4. MOSI seed=42 60ep。

进入主模型候选的最低标准：

| 条件 | 要求 |
|---|---|
| ACC2_NZ_reg | ≥ P4W + 1.0% |
| MAE | 不高于 P4W |
| Corr | 不低于 P4W |
| AWAF 权重 | 不坍缩 |
| reliability gate | r_a/r_v 有样本差异 |
| 多 seed | seed=42、2024 趋势一致 |

若 seed=42 未超过 P4W，不补跑 seed=2024，直接输出失败分析。
