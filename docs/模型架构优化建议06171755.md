# 模型架构优化建议06171755

> 阶段：P5D 代码审计后架构优化建议  
> 目标：在不偏离“xLSTM + 自适应注意力机制”导师要求的前提下，继续提升 MOSI 主模型性能。  
> 当前状态：P5D 2-seed mean ACC2_NZ_reg = 81.25%，稳定超过 DeepMLP text-only 80.2%，但未达到 82/83/85/88 目标。

---

## 1. 总体判断

P5D 的结论不是“架构失败”，而是：

```text
DeepText-xLSTM-AWAF Residual 路线成立，但当前 residual correction 过弱。
```

证据：

| 模型/阶段 | ACC2_NZ_reg | 说明 |
|---|---:|---|
| DeepMLP text-only | 80.2% | 当前强文本基线 |
| P4W AWAF-Seq | 78.8% | 旧三路 sLSTM 平权融合 |
| P5D DeepText-xLSTM-AWAF Residual | 81.25% | 2-seed mean，稳定超过 text-only |

但 residual 诊断也暴露了关键问题：

1. residual 只带来 +1.05%，贡献太小；
2. 50.4% 样本被改善、49.6% 被破坏，说明 residual correction 近似中性；
3. weak_neg 有改善，但 strong_neg 被过度修正；
4. 当前 `final = text_base + δ * delta` 是无条件残差，缺少“何时修正”的约束；
5. loss 里没有直接监督 residual 学习 `label - text_base`，因此 residual 分支只能通过 final loss 间接学习，信号太弱；
6. 当前 AWAF 权重作用于融合表示 `z_residual`，再由一个 delta head 输出修正，权重解释与实际修正贡献之间仍有间隔。

因此下一步不应继续盲目堆模块，而应围绕 “残差修正为什么弱” 做结构性改造。

---

## 2. 当前代码审计发现的关键风险

### 2.1 Residual 公式方向正确，但需要条件化和显式监督

当前公式：

```text
reg_final = reg_text_base + delta_scale_reg * delta_reg
```

方向是科学合理的，因为强文本主干保留主判别能力，xLSTM/AWAF 负责音视频残差修正。

但它的缺陷是：所有样本都被修正。更合理的公式是：

```text
effective_delta = gate(x) * delta_scale * bounded_delta
reg_final = reg_text_base + effective_delta
```

其中 gate 应主要在文本不确定、弱极性、模态冲突样本上放大，在 strong_pos/strong_neg 上收缩。

### 2.2 当前 loss 没有显式训练 delta 学习 correction target

当前 residual 分支只通过 final prediction 的 L1/BCE/sign loss 间接获得梯度。建议新增：

```text
target_delta = label - detach(reg_text_base)
L_delta_target = SmoothL1(effective_delta, target_delta)
```

这会把 residual branch 的任务从“隐式辅助预测”改成“显式误差修正”，更符合 residual model 的第一性原理。

### 2.3 当前 sample reweight 代码需要先修

审计发现 sample reweight 逻辑应确认是否使用 `reduction='none'`，否则 sample weight 只是在 scalar loss 后乘平均权重，不能实现真正的逐样本重加权。

下一轮必须把重加权写成：

```python
per_sample_l1 = F.l1_loss(pred, target, reduction='none')
loss = (per_sample_l1 * sample_weight).mean()
```

### 2.4 two-stage trainer 需要恢复 Stage 1 最佳 text state

两阶段训练方向正确，但 Stage 1 结束后必须显式 load text best state，再进入 Stage 2。否则 Stage 2 可能从 text branch 的最后 epoch 而不是最佳 epoch 开始。

### 2.5 one-stage 脚本需要支持 residual gate / loss v2 开关

当前 one-stage 主训练入口必须支持：

```yaml
use_uncertainty_gate: true
delta_target_loss_weight: 0.2
bounded_delta: true
max_delta: 1.5
sample_reweight_enabled: true
```

否则 P5D 已实现的模块难以被标准训练入口调用。

## 3. 建议的新架构：P5E UGR-AWAF Residual

建议 P5E 不重写主线，而是在 P5D 基础上升级为：

```text
DeepText-xLSTM-UGR-AWAF Residual
```

中文名建议：

```text
基于不确定性感知 xLSTM 残差增强与自适应加权注意力的多模态情感分析模型
```

其中 UGR = Uncertainty-Guided Residual。

### 3.1 新结构

```text
Text branch:
DeBERTa-large token features
→ Masked Attention Pooling
→ DeepMLP
→ reg_text_base / cls_text_base

Audio branch:
wav2vec2 frame features
→ projection
→ sLSTM / xLSTM
→ attention pooling
→ h_a

Vision branch:
CLIP frame features
→ projection
→ sLSTM / xLSTM
→ attention pooling
→ h_v

Text residual branch:
DeBERTa features
→ lightweight projection + attention pooling
→ h_t_residual

AWAF residual expert branch:
[h_t_residual, h_a, h_v]
→ AWAF weights w_t, w_a, w_v
→ modality-specific delta experts delta_t, delta_a, delta_v
→ delta_awaf = w_t*delta_t + w_a*delta_a + w_v*delta_v

Uncertainty residual gate:
text confidence + AWAF entropy + delta magnitude + residual representation
→ gate ∈ [0,1]

effective_delta = gate * delta_scale * max_delta * tanh(delta_awaf)

Final:
reg_final = reg_text_base + effective_delta
cls_final = cls_text_base + gate_cls * delta_scale_cls * bounded_delta_cls
```

---

## 4. 为什么这个方向比继续小修更合理

### 4.1 让 residual branch 显式学习“误差修正”

P5D 当前 residual 效果很小，是因为 delta 没有显式目标。P5E 新增 delta target loss 后，audio/vision xLSTM + AWAF 的目标变得明确：

```text
预测 text branch 尚未解释的部分。
```

### 4.2 让 AWAF 权重更可解释

当前：

```text
AWAF → z_residual → delta_head
```

权重和最终 delta 间接相关。

建议改成：

```text
delta_awaf = w_t*delta_t + w_a*delta_a + w_v*delta_v
```

这样论文中可以解释为：

```text
AWAF 直接决定各模态 residual expert 对最终修正项的贡献。
```

### 4.3 避免强样本被过度修正

P5D 显示 strong_neg 被过度修正。UGR gate 根据文本置信度控制修正幅度：

```text
|reg_text_base| 大 → text confident → gate 小
|reg_text_base| 小 → text uncertain → gate 大
```

这比普通 MLP gate 更有先验约束。

### 4.4 保持导师指定主题

新模型仍然明确包含：

1. xLSTM / sLSTM：用于 audio / vision 时序残差建模；
2. 自适应注意力机制 AWAF：用于样本级 residual expert 加权；
3. 多模态残差融合：是当前主要创新点；
4. 可解释权重：AWAF weights + residual gate + delta contribution。

## 5. P5E 应执行的实验顺序

不要一开始跑所有组合。建议按以下顺序：

### Step 0：先修代码缺陷

1. 修复 `attention_pooling.py` 返回表达式；
2. 修复 sample reweight 为 per-sample loss；
3. 修复 two-stage Stage1 best state 恢复；
4. one-stage 支持 gate / loss v2 / delta target 配置；
5. 保存 `effective_delta`、`gate`、`delta_experts` 到 CSV。

### Step 1：运行诊断 ablation

先跑 30ep：

1. no_residual；
2. no_audio；
3. no_vision；
4. no_awaf_mean；
5. text_slstm_on。

目的不是论文消融，而是判断 residual branch 的噪声来源。

### Step 2：UGR-AWAF v2 seed42

运行：

```text
use_uncertainty_gate = true
use_delta_experts = true
delta_target_loss_weight = 0.2
bounded_delta = true
max_delta = 1.5
```

若 seed42 ≥ 82%，补 seed2024。若低于 81.25%，回滚该模块。

### Step 3：Two-stage + delta target

两阶段训练：

```text
Stage 1: text-only，复现 80.2%
Stage 2: freeze text，训练 residual，使用 delta target loss
Stage 3: 小学习率 joint fine-tune
```

若 Stage1 低于 80%，先修 text branch，不进入 Stage2。

### Step 4：WeakNeg reweight

仅当 delta target 有效时再加入 weak_neg reweight。否则样本重加权可能只是在噪声上放大 loss。

## 6. 性能目标与决策阈值

| 阶段 | 目标 | 决策 |
|---|---:|---|
| P5E seed42 | ≥82.0% | 说明结构优化有效，补 seed2024 |
| P5E 2-seed mean | ≥82.5% | 可以继续调参或补 seed1234 |
| P5E 2-seed mean | ≥83.0% | 可进入正式主模型候选 |
| P5E 仍 <82.0% | — | 不再继续架构微调，转 P5F 强特征升级 |
| 要冲 85/88 | — | 大概率需要更强 text/audio/vision features |

必须直说：仅靠当前 DeBERTa-large/wav2vec2-base/CLIP-B 特征和结构微调，从 81.25 直接冲 88 不现实。P5E 的合理目标是 82–83；85+ 需要 P5F 强特征升级。
