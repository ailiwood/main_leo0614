# docs/经验总结.md — 项目经验与避坑规则

## 1. 特征工程经验

1. **T=1 不能支撑时序建模主张**：TMDC-v1 T=1 pooled features 虽有强预训练模型，但无法让 sLSTM 展示时序优势
2. **强预训练特征 >> 弱对齐序列特征**：DeBERTa 1024d + wav2vec2 768d + CLIP 1024d 的 T=1 表现（75.25%）远优于 GloVe + COVAREP + FACET 的 T~12（44.9%）
3. **强序列特征构建成功但 C0 架构不足**：自建 DeBERTa token-level + wav2vec2 frame-level 序列特征成功（T>1），但 C0 仍不足
4. **视觉 T=1 是当前瓶颈**：MOSI Frames/ 只有预提取的 .pt 单向量，无法构建视觉序列

## 2. 评估协议经验

1. **不能用 test set 选择 best epoch**：P4A 存在 test leakage，结果不可信
2. **strict protocol 必须**：train 只训练、val 选 best、test 仅评估一次
3. **ACC2 必须区分 reg_sign 与 cls_logit**：MMSA 标准用 reg_pred sign
4. **每个 epoch 只记录 val metrics**，test 仅在训练结束后使用

## 3. 模型设计经验

1. **DEConv/CME/Data2Vec 不进入当前主模型**：候选模块逐一失败（不稳定性、退化、特征提取失败）
2. **Modality dropout 有效**：md_prob=0.2 比 0.1 好 ~2%
3. **AWAF entropy regularization 不采用**：有帮助但不及加强 md
4. **视觉 T=1 限制了 whole pipeline**：需要帧级视觉特征

## 4. 工程经验

1. **旧代码和旧实验产物不进入 Git**：已清理
2. **GitHub 不上传 outputs/data/cache/checkpoints**
3. **PyTorch stable cu128 支持 Blackwell (sm_120)**：2.11.0 可用
4. **强序列特征提取速度快**：2199 样本 2.1 分钟
