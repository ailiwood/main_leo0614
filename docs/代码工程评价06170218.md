## 1. 总体结论

P4U.1 已经修复此前阻塞架构审阅的关键工程问题：

1. `data/*.py` 已进入 Git，不再被 `.gitignore` 错误排除；

3. `check_val()` 已移除 `test_loader` 参数，降低 test leakage 风险；
4. `configs/data/mosi_strong_sequence.yaml` 与 `configs/models/ours_c0_strong_sequence.yaml` 已固化 strong sequence 维度；
5. mask invariance、import、forward/backward、strict trainer dry-run 已通过。

因此，当前仓库可以进入架构升级设计阶段。

但仍需强调：当前 C0 模型不能直接作为论文主模型终版。C0 结构仍是：

```text
三模态强序列特征
→ 三路 projection
→ 三路 sLSTM
→ 单模态池化 pooled h_t/h_a/h_v
→ AWAF 样本级融合
→ 回归/分类头
```

这个结构虽然开始使用 T>1 text/audio 序列，但在跨模态交互前已经将序列压缩为单向量，因此没有真正利用 token/frame 级跨模态对齐信息。

## 2. 当前工程状态评价

### 2.1 优点

当前工程已有较好的基础：

1. **主线代码较清晰**：`models/ours_xlstm_fusion.py`、`models/encoders/slstm.py`、`models/fusion/awaf.py`、`engine/strict_trainer.py` 已形成可运行链路。
2. **strict protocol 已建立**：train 只训练，val 选 best，test final once。
3. **指标双口径已区分**：`reg_sign` 与 `cls_logit` 都可输出，避免 MMSA 口径混淆。
4. **强序列特征已构建**：text 为 DeBERTa token-level，audio 为 wav2vec2 frame-level，vision 当前为 CLIP 单向量。
5. **数据代码已补齐进 Git**：后续可进行完整代码审阅。
6. **AWAF 实现独立**：保留了样本级自适应权重输出，适合作为论文解释模块。

### 2.2 主要缺陷

当前缺陷集中在模型结构层面，而不是简单工程 bug：

1. **缺少 sequence-level cross-modal interaction**  
   当前三模态先独立编码并池化，再做 AWAF。文本 token 与音频 frame、视觉 frame 之间没有显式交互。

2. **sLSTM 的完整序列输出没有被下游充分使用**  
   `SLSTMEncoder` 返回 `H` 和 `pooled`，但 C0 主模型主要使用 `pooled`，丢失了 `H_t/H_a/H_v` 中的细粒度时序轨迹。

3. **AWAF 目前是 utterance-level fusion，不是 sequence-level fusion**  
   AWAF 输入为三个模态摘要向量，适合解释样本级模态贡献，但不能承担 token/frame 级对齐任务。

4. **vision 仍为 T=1**  
   当前 strong sequence 实际是：text T>1，audio T>1，vision T=1。这意味着视觉仍没有时序建模证据。

5. **C0 strong sequence 旧结果需重新校准**  
   P4T.1 的 C0 strong sequence 结果是在 evaluate mask bug 修复前得到的，不能作为最终架构判断依据。P4V 必须先重跑 C0_fixed。

6. **多任务头可能存在目标冲突**  
   主流 MOSI/MOSEI ACC2 常按 regression sign 计算，而当前仍有独立 classification head 和 BCE loss。后续应降低分类头权重或将其作为辅助。

## 3. 架构层面判断

当前最佳升级方向不是删除 AWAF，也不是回到普通 Transformer，而是：

```text
强序列特征
→ 三路 sLSTM 时序编码
→ 序列级 Cross-modal Transformer
→ 模态级 Masked Attention Pooling
→ AWAF 样本级动态融合
→ 回归/分类头
```

该结构将职责分开：

| 模块 | 职责 |
|---|---|
| sLSTM | 单模态长程时序记忆编码 |
| Cross-modal Transformer | token/frame 级跨模态交互 |
| Masked Attention Pooling | 从上下文增强序列中得到模态摘要 |
| AWAF | 样本级三模态贡献动态加权和解释 |
| Heads | 情感强度回归与辅助分类 |

这条路线与论文题目“扩展 LSTM 与 Transformer”一致，也保留 AWAF 的论文创新位置。
