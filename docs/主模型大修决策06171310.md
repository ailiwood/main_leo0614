## 1. 为什么 P4W AWAF-Seq 不能作为最终主模型

P4W AWAF-Seq 是当前最好多模态模型（ACC2_NZ_reg=78.4%/seed42=78.8%），但存在根本性问题：

### 1.1 关键实验事实

| 模型 | ACC2_NZ | MAE | Corr | 参数量 | 说明 |
|------|---------|-----|------|--------|------|
| Text+sLSTM (P4Z) | 76.2% | 1.004 | 0.656 | ~855K | sLSTM on text |
| **DeepMLP text-only** | **80.2%** | **0.885** | **0.733** | **~592K** | **NO sLSTM** |
| Full AWAF-Seq (P4W) | 78.8% | 0.994 | 0.645 | 4.15M | Current best multimodal |

### 1.2 核心诊断

1. **Text-side sLSTM 是反作用**：DeBERTa token features → sLSTM 使 ACC2 从 80.2% 退化到 76.2%（-4.0%）
2. **多模态融合当前有害**：Full AWAF-Seq (78.8%) < DeepMLP text-only (80.2%)
3. **旧三路 sLSTM 平权融合路线从根上错误**：text 分支不应使用 sLSTM
4. **DeBERTa tokens 已经充分上下文化**：sLSTM 添加的是时序噪声而非有用信息

### 1.3 P4W 的架构问题

P4W AWAF-Seq 使用三路 sLSTM + CrossModalTransformer + AWAF，但 text 侧的 sLSTM 在 DeBERTa 已经充分编码的 token features 上施加了不必要的递归变换，本质是"先破坏再修补"。

---

## 2. 为什么 P5A Text-Guided AWAF-xLSTM 失败

P5A 尝试将 text 作为"主导模态"引导 audio/vision 的 xLSTM 编码，但：

- ACC2_NZ_reg = 75.5%（远低于 80.2% 的纯 text 上限）
- MAE = 1.053
- Corr = 0.611

失败原因：
1. Text-guided 机制破坏了 audio/vision sLSTM 的独立时序建模能力
2. 设计上仍然保留了 text-sLSTM（继承自旧路线），无法避免 text 侧的退化
3. 没有认识到 text 本身就已经是最强判别源

---

## 3. 为什么 P5B 证明 text-side sLSTM 反作用

P5B 通过控制变量实验直接证明了因果链：

| 变量 | ACC2 | Δ |
|------|------|---|
| Text + sLSTM (P4Z 单模态) | 76.2% | baseline |
| Text + DeepMLP (NO sLSTM) | 80.2% | **+4.0%** |
| Full multimodal (P4W) | 78.8% | -1.4% vs text-only |

结论：**DeBERTa token → sLSTM 是因果反作用**，不是数据噪声或超参问题。

---

## 4. 最终决策：DeepText-xLSTM-AWAF Residual

### 4.1 新架构名称

**中文**：基于 xLSTM 时序残差增强与自适应加权注意力的多模态情感分析模型

**英文**：DeepText-xLSTM-AWAF Residual Model

### 4.2 核心设计原则

```text
1. Text branch 是主判别分支 — 使用 DeepMLP，不使用 sLSTM
2. xLSTM 用于 audio / vision 时序残差增强
3. AWAF 负责样本级 residual correction 权重
4. Final = text_base + λ * residual_correction
```

### 4.3 架构结构

```text
输入: text [B,Tt,1024], audio [B,Ta,768], vision [B,Tv,768]

┌─────────────────────────────────────────────────────┐
│ Text Branch (主判别分支, NO sLSTM)                    │
│   projection → Masked Attention Pooling → DeepMLP     │
│   → reg_text_base, cls_text_base                      │
│   → h_text_base                                       │
├─────────────────────────────────────────────────────┤
│ Audio Branch (残差增强分支)                            │
│   projection → sLSTM encoder → Attention Pooling       │
│   → h_a                                               │
├─────────────────────────────────────────────────────┤
│ Vision Branch (残差增强分支)                           │
│   projection → sLSTM encoder → Attention Pooling       │
│   → h_v                                               │
├─────────────────────────────────────────────────────┤
│ Text Residual Branch (轻量, NO sLSTM)                  │
│   projection → Attention Pooling only                  │
│   → h_t_residual                                      │
├─────────────────────────────────────────────────────┤
│ AWAF Residual Fusion                                  │
│   AWAF(h_t_residual, h_a, h_v)                        │
│   → z_residual, awaf_weights                          │
│   → delta_reg, delta_cls                              │
├─────────────────────────────────────────────────────┤
│ Final Prediction                                      │
│   reg = reg_text_base + δ_reg * delta_reg              │
│   cls = cls_text_base + δ_cls * delta_cls              │
│   δ_reg_init = δ_cls_init = 0.1 (可学习)               │
└─────────────────────────────────────────────────────┘
```

## 5. xLSTM 在新模型中的位置

xLSTM (sLSTM) 在新模型中**仅用于 audio 和 vision 分支的时序残差增强**：

- Audio: wav2vec2 frame features → sLSTM → h_a
- Vision: CLIP frame features → sLSTM → h_v
- Text: **不使用 sLSTM**（DeepMLP + Attention Pooling 替代）

xLSTM 的角色从"三路平权编码器"变为"非文本模态的时序增强器"。

---

## 6. AWAF 在新模型中的位置

AWAF 从"三路融合器"变为"残差修正权重生成器"：

- 输入：h_t_residual (轻量 text projection), h_a, h_v
- 输出：样本级三模态权重 + residual correction delta
- 功能：根据当前样本的跨模态一致性决定 correction 的幅度和方向
- 解释性：权重可保存、可视化、与情感强度相关分析

---

## 7. 如何满足导师要求的 xLSTM + 自适应注意力机制

1. **xLSTM**：在 audio 和 vision 分支中作为时序编码器，对论文题目"基于扩展 LSTM"形成支撑
2. **自适应加权注意力机制 (AWAF)**：在 residual fusion 中生成样本级动态权重，是可输出、可解释的创新模块
3. **新架构更科学**：不是"因为有 xLSTM 所以用 xLSTM"，而是"在最适合 xLSTM 的位置使用 xLSTM"

---

## 8. 对论文第 3/4/5 章的影响

### 第 3 章（方法描述）

- 不能再描述"三路 sLSTM 平权编码 → AWAF 融合"的旧架构
- 必须改为"文本主导的 DeepMLP 编码 + 音视频 xLSTM 残差增强 + AWAF 残差修正"
- AWAF 公式不变，但输入和用途从"主融合"变为"残差权重生成"

### 第 4 章（实验设计）

- 消融项需要重设：
  - `no_residual`（仅 text 分支）
  - `no_audio` / `no_vision`
  - `text_slstm_on`（消融验证 text sLSTM 有害）
  - `no_awaf_mean_residual`（AWAF → mean pooling 残差）
  - 旧 sLSTM→LSTM/GRU 消融改为在 audio/vision 分支进行

### 第 5 章（结果分析）

- AWAF 权重解释：从"三模态贡献"变为"残差修正中各模态的贡献"
- 不能写"xLSTM 对 text 的时序建模重要"
- 必须写"xLSTM 对 audio/vision 的时序残差增强有效"
