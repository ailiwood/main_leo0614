# 架构升级方案.md

> 阶段：P4V  
> 方案名称：AWAF-Seq + Cross-modal Transformer  
> 目标：在保留 sLSTM 与 AWAF 核心创新的前提下，引入序列级跨模态交互，使模型能够真实利用 strong sequence 特征。

---

## 1. 升级动机

当前 C0 模型的主要问题是：三模态各自经过 sLSTM 后立即池化为 `h_t/h_a/h_v`，然后进入 AWAF。这样 AWAF 只能处理三个样本级摘要向量，无法建模文本 token、音频 frame、视觉 frame 之间的局部交互。

因此，架构升级的核心不是替换 AWAF，而是将 AWAF 放在更合适的位置：

```text
sLSTM 序列编码之后
Cross-modal Transformer 序列交互之后
Masked Attention Pooling 之后
```

即 AWAF 不承担 sequence-level alignment，而专注于 sample-level adaptive fusion。

---

## 2. 新模型结构

### 2.1 总体结构

```text
text_seq / audio_seq / vision_seq
        ↓
modality-specific projection
        ↓
three independent sLSTM encoders
        ↓
H_t, H_a, H_v  （保留完整序列）
        ↓
CrossModalTransformerEncoder
        ↓
H_ctx_t, H_ctx_a, H_ctx_v
        ↓
MaskedAttentionPooling per modality
        ↓
h_t, h_a, h_v
        ↓
AdaptiveWeightedAttentionFusion (AWAF)
        ↓
Z = w_t h_t + w_a h_a + w_v h_v
        ↓
RegressionHead + ClassificationHead
```

### 2.2 模块职责

| 模块 | 输入 | 输出 | 职责 |
|---|---|---|---|
| Projection | 原始强序列特征 | 共享 hidden_dim | 统一维度 |
| sLSTM | 单模态序列 | 单模态时序隐藏序列 | 长程单模态记忆 |
| Cross-modal Transformer | 拼接三模态序列 | 上下文增强序列 | 跨模态 token/frame 交互 |
| Masked Attention Pooling | 上下文增强序列 | 模态摘要向量 | 学习有效时间步贡献 |
| AWAF | 三个模态摘要 | 融合表示 + 权重 | 样本级动态模态融合与解释 |
| Heads | 融合表示 | reg/cls | 预测 |

## 3. 新增核心文件

### 3.1 `models/interaction/cross_modal_transformer.py`

新增 `CrossModalTransformerEncoder`：

- 输入 `H_t/H_a/H_v` 和三模态 mask；
- 添加 modality type embedding；
- 拼接三模态序列；
- 使用 `nn.TransformerEncoder` 做跨模态交互；
- 按原长度切回 `H_ctx_t/H_ctx_a/H_ctx_v`；
- 支持不同模态不同序列长度；
- 支持 vision T=1；
- 使用 `src_key_padding_mask` 屏蔽 padding。

### 3.2 `models/pooling/attention_pooling.py`

新增 `MaskedAttentionPooling`：

- 输入 `[B,T,D]` 与 mask；
- 对有效时间步计算 attention score；
- padding 位置权重为 0；
- 输出 pooled vector 与 attention weights；
- 支持全 padding 样本安全 fallback。

### 3.3 `models/ours_awaf_seq_xlstm.py`

新增 `OursAWAFSeqXLSTM`：

- 保留三路 sLSTM；
- 使用 Cross-modal Transformer 进行序列级交互；
- 使用 MaskedAttentionPooling 获取模态摘要；
- 使用原 AWAF 做样本级融合；
- 返回 reg/cls/awaf_weights/pool attention 等可解释信息；
- forward 接口兼容 `StrictTrainer`。

### 3.4 `configs/models/ours_awaf_seq_xlstm.yaml`

新增 AWAF-Seq 配置，默认：

- hidden_dim = 256
- cross_num_layers = 2
- cross_num_heads = 4
- cross_ffn_dim = 512
- cross_dropout = 0.2
- pooling_type = attention
- batch_size = 16
- cls_loss_weight = 0.3

### 3.5 `scripts/test_awaf_seq_modules.py`

新增模块测试：

- CrossModalTransformer shape/mask/backward；
- MaskedAttentionPooling 权重和 padding；
- AWAF-Seq forward/backward；
- AWAF 权重 sum=1；
- padding noise invariance。

### 3.6 `scripts/train_awaf_seq.py`

新增训练脚本：

- 加载 strong sequence dataset；
- 使用 `StrictTrainer`；
- val MAE 选 best；
- test final once；
- 输出完整 run 产物。

## 4. 实验流程

### 4.1 C0_fixed 重跑

先用修复后的 `strict_trainer.py` 重跑 C0：

```text
model: OursXLSTMFusion
config: configs/models/ours_c0_strong_sequence.yaml
dataset: MOSI strong sequence
seeds: 42, 2024
epochs: 40
best: val MAE
test: final once
```

目的：建立可信对照。

### 4.2 AWAF-Seq smoke

```text
model: OursAWAFSeqXLSTM
seed: 42
epochs: 3
```

目的：验证新架构可运行。

### 4.3 AWAF-Seq 初训

```text
model: OursAWAFSeqXLSTM
seeds: 42, 2024
epochs: 40
batch_size: 16
best: val MAE
test: final once
```

### 4.4 对比标准

| 条件 | 判断 |
|---|---|
| AWAF-Seq 平均提升 ≥ 2%，且两个 seed 都不退化 | 可作为下一轮主模型候选 |
| 提升 1%–2% | 需要调参和补强视觉 |
| 提升 < 1% | 模型升级不足，应优先补 vision T>1 或重审特征 |
| seed 方差大 | 暂不能入论文主表 |

## 5. 论文表述边界

1. 可以写：模型引入 sLSTM 做单模态时序编码；
2. 可以写：Cross-modal Transformer 做序列级跨模态交互；
3. 可以写：AWAF 输出样本级三模态权重；
4. 不能写：当前 vision 已完成帧级时序建模；
5. 不能写：P4A/P4T.1 结果是最终论文结果；
6. 不能写：AWAF 替代了 Transformer；
7. 不能写：DEConv/CME/Data2Vec 是最终主模型模块。

---

## 6. 后续升级预留

若 P4V AWAF-Seq 有效，可继续：

1. 补视觉帧级 CLIP features；
2. 加入 cross-modal residual gate；
3. 引入 sign consistency loss；
4. 引入 modality-aware auxiliary heads；
5. 做 AWAF-Seq 消融：
   - no cross transformer
   - no modality embedding
   - mean pooling vs attention pooling
   - AWAF vs gated/concat/mean
   - sLSTM vs LSTM/GRU
