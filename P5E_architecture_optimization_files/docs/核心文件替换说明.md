# P5E 核心文件替换说明

本包不是要求直接覆盖当前 P5D 主模型，而是提供 P5E 候选升级文件。CC 应在新分支中复制并接入，完成单元测试后再训练。

## 新增文件

| 文件 | 作用 |
|---|---|
| `models/modules/uncertainty_residual_gate.py` | 不确定性感知残差门控，替代普通 ConditionalResidualGate 候选 |
| `models/deeptext_xlstm_awaf_residual_v2.py` | P5E UGR-AWAF Residual V2 主模型候选 |
| `engine/residual_losses_v2.py` | 修复逐样本重加权并新增 delta target loss |
| `configs/models/deeptext_xlstm_awaf_residual_v2_mosi.yaml` | P5E MOSI 配置 |
| `docs/模型架构优化建议06171755.md` | 架构优化建议 |

## 必须先修的旧文件问题

1. `models/pooling/attention_pooling.py` 的返回表达式建议改为显式分支：

```python
if return_weights:
    return pooled, attn
return pooled
```

2. `engine/losses.py` 中 sample reweight 必须使用 `reduction='none'`。

3. `scripts/train_deeptext_xlstm_awaf_residual_twostage.py` 在 Stage 1 结束后必须 load best text state，再进入 Stage 2。

4. `scripts/train_deeptext_xlstm_awaf_residual.py` 需要支持 V2 model、V2 loss、gate/delta target 配置。

## 建议实验顺序

1. 代码修复 + 单元测试；
2. diagnostic ablation 30ep；
3. V2 one-stage seed42 60ep；
4. 若 seed42 ≥82%，补 seed2024；
5. 若 V2 one-stage 有效，再跑 V2 two-stage；
6. 最后再尝试 weak_neg reweight。
