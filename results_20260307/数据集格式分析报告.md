## 二、CMU-MOSI 数据格式

### 2.1 目录结构

```
data/mosi/
├── label.csv              # 标签文件
├── Raw/                   # 原始视频 (MP4)
│   ├── {video_id}/
│   │   ├── 1.mp4, 2.mp4, ...
├── Frames/                # 视频帧序列
│   ├── {video_id}/
│   │   ├── 1.jpg, 2.jpg, ... (每视频约 10-20 帧)
├── wav/                   # 音频文件
│   ├── {video_id}/
│   │   ├── 1.wav, 2.wav, ...
```

### 2.2 标签文件格式 (label.csv)

| 列名 | 说明 | 示例 |
|------|------|------|
| video_id | 视频唯一标识 | 03bSnISJMiM |
| clip_id | 片段编号 | 11 |
| text | 文本内容 | A LOT OF SAD PARTS |
| label | 情感分数 (主标签) | -0.5 |
| label_T | 文本模态标签 | - |
| label_A | 音频模态标签 | - |
| label_V | 视频模态标签 | - |
| annotation | 情感类别 | Neutral/Negative/Positive |
| mode | 数据划分 | train/test |

### 2.3 标签分布

- **训练集**：约 1,284 样本
- **测试集**：约 461 样本
- **验证集**：约 454 样本
- **标签范围**：[-2.8, +2.5]（连续值）

### 2.4 特征维度（需预处理）

- **文本**：RoBERTa-large 输出 1024 维
- **音频**：Data2Vec-Audio-large 输出 1024 维
- **视频**：每帧图像特征 + DEConv 输出

## 三、CMU-MOSEI 数据格式

### 3.1 目录结构

```
data/CMU-MOSEI/
├── train.features         # 训练集特征 (pickle)
├── val.features           # 验证集特征 (pickle)
├── test.features          # 测试集特征 (pickle)
├── w2v.vectors            # Word2Vec 词向量
└── CMU-MOSEI-20230514T151450Z-001/CMU-MOSEI/
    ├── Audio_chunk/        # 音频文件
    │   ├── Train_modified/
    │   ├── Val_modified/
    │   └── Test_modified/
    └── Labels/            # 标签 CSV
        ├── Data_Train_modified.csv
        ├── Data_Val_modified.csv
        └── Data_Test_modified.csv
```

### 3.2 标签文件格式

| 列名 | 说明 |
|------|------|
| video | 视频唯一标识 |
| start_time | 起始时间 |
| end_time | 结束时间 |
| sentiment | 情感分数 (主标签, [-3, +3]) |
| happy/sad/anger/surprise/disgust/fear | 细粒度情感标签 |
| text | 原始文本 |
| ASR | 自动语音识别文本 |

### 3.3 数据集划分

| 划分 | 样本数 | 标签文件 |
|------|--------|----------|
| 训练集 | 16,282 | Data_Train_modified.csv |
| 验证集 | 1,862 | Data_Val_modified.csv |
| 测试集 | 4,655 | Data_Test_modified.csv |
| **合计** | **22,799** | - |

### 3.4 30% 采样方案

- **采样方式**：随机采样（固定种子 42）
- **采样后数量**：约 6,885 训练 + 559 验证 + 1,397 测试 ≈ 7,000
- **保存**：采样索引保存为 JSON 文件

## 四、数据加载接口设计要点

### 4.1 统一接口设计

两个数据集的共同点：
- 任务类型相同（回归）
- 标签空间相同（[-3, +3]）
- 评价指标相同（MAE, Corr, ACC2, F1, ACC7）

### 4.2 需要适配的部分

| 模块 | MOSI | MOSEI | 适配方案 |
|------|------|-------|----------|
| 数据路径 | data/mosi/ | data/CMU-MOSEI/ | 配置化 |
| 标签文件 | label.csv | Data_*_modified.csv | 字段映射 |
| 文本特征 | RoBERTa 实时提取 | features 文件加载 | 预处理缓存 |
| 音频特征 | Data2Vec 实时提取 | features 文件加载 | 预处理缓存 |
| 视频特征 | 视频帧+DEConv | 未提供 | 仅使用 T+A |

### 4.3 推荐处理方案

1. **MOSEI 优先使用预处理特征**：train.features 等文件包含预提取的多模态特征
2. **MOSI 需要预处理**：原始视频/音频需提取特征
3. **简化方案**：第一阶段仅使用 T+A 模态（文本+音频），避免视频特征处理
