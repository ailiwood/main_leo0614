## 关键发现

### 1. AWAF 权重修复成功
- R1 (无 entropy): 权重逐渐 collapse (entropy 0.58)
- R2 (entropy=0.01): 权重保持均匀 (entropy 1.005, max=1.099)
- R3 (umix 0.10): 也有改善 (entropy 0.912)
- **结论**: λ_entropy=0.01 成功防止 AWAF 权重崩溃

### 2. Gate 始终关闭 (0.30-0.34)
- 4 个 config 中 gate 最终值都 ≈0.33
- 初始 gate_bias=2.0 → sigmoid≈0.88，训练后降至 0.33
- **结论**: 模型学会抑制 residual，因为 audio/vision 残差无益

### 3. Delta 始终很小 (0.014-0.018)
- 虽然 dsr=0.2 (vs 原 0.02 = ×10), 但有效 delta 仅 0.014-0.018
- gate × delta_scale × bounded_delta ≈ 0.33 × 0.2 × 0.1 ≈ 0.007
- **结论**: residual 贡献可忽略

### 4. 最佳配置: R2
- val_ACC2=87.96%, 比 R1 +0.46%
- AWAF 权重健康
- 但 residual gain 可能仍接近零

## 根本问题

所有 R1-R4 中 gate 在训练中主动关闭，delta 极小。这指向架构级问题：

1. **Audio/vision 特征噪声过大**: frozen 768d → Linear → sLSTM 的轻量管线可能无法从 frozen features 提取有用信号
2. **Delta alignment loss 太弱**: λ=0.2 不足以推动 residual 产生正增益
3. **Gate 缺乏正向激励**: gate 没有 loss 项鼓励其开启
4. **Text branch 已经足够好**: 86-87% text_base 天花板让 residual 难以增量
